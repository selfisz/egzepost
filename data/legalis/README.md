# Legalis editorial titles

PDFs used only for **article short titles** (`Art. N [Tytuł]`), not for body text.

| File | Act |
|------|-----|
| `upea.pdf` | u.p.e.a. |
| `kpa.pdf` | Kpa |
| `ordynacja.pdf` | Ordynacja podatkowa (Op) |

Official article bodies remain from `data/source/*Lj.pdf` via `npm run import:acts`.

Merge titles: `npm run import:titles`.
